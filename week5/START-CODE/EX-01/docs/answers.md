# Reflective Questions
## Q1 - How did using useEffect() and axios help separate logic from UI?
``useEffect()`` handles side effects for fetching data and others method.
Axios handles API request such as loading, error and success.

## Q2 - What state challenges did you face while managing form input and API response?
I needed to manage multiple states such as form values, loading status, error messages, and API response data.

## Q3 - How does REST structure help React developers write cleaner frontend code?
REST provides consistent and predictable endpoints for different operations.
Because each endpoint has a clear purpose, React developers can easily map API calls to frontend actions without needing to know how the backend is implemented.
