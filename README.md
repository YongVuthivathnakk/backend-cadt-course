# CADT Backend REST API Course

This repository contains the backend development exercises and practice projects completed from Week 1 to Week 9 as part of the Cambodia Academy of Digital Technology (CADT) course.

The course focuses on building RESTful APIs using modern backend development practices with JavaScript, Node.js, and Express.js. Each week introduces new concepts and gradually builds toward a complete school management system with API endpoints, data models, controllers, routes, and frontend integration.

## Course Overview

This course is designed to help learners understand how backend systems work, how APIs communicate with clients, and how data is managed in real-world applications.

### Main Topics Covered
- JavaScript and Node.js fundamentals
- Creating and managing HTTP servers
- REST API design and endpoints
- Express.js routing and middleware
- MVC architecture patterns
- Data modeling with Mongoose / MongoDB concepts
- CRUD operations for resources
- Error handling and validation
- Full-stack integration between backend and frontend
- Building a school management API and dashboard

## Weekly Progress

### Week 1
Introduction to backend basics and JavaScript programming foundations.
- JavaScript exercises
- Node.js basics
- File handling and small programs
- Project setup and package management

### Week 2
Introduction to server-side development and HTTP concepts.
- Building simple servers
- Understanding requests and responses
- Basic REST API concepts
- API testing with local endpoints

### Week 3
Working with modules, data flow, and API logic.
- Structured code organization
- Creating services and models
- Handling data and logic in separate files
- Practice with course-related API examples

### Week 4
Applying MVC-style architecture in backend apps.
- Controllers, routes, and models
- Middleware for validation and request handling
- Cleaner project structure
- Express application organization

### Week 5
Frontend and backend project integration.
- Vite frontend setup
- API communication with frontend applications
- UI and API connection basics
- Project structure for full-stack development

### Week 6
Full-stack application setup and backend/front-end coordination.
- Environment configuration
- Frontend + backend project connection
- API integration in web apps
- Handling data exchange between client and server

### Week 7
Implementing real application features with CRUD operations.
- Student, class, and attendance management
- RESTful resource routes
- Database models and controller logic
- API endpoints for academic records

### Week 8
School API development with a more complete backend structure.
- Centralized app architecture
- Seed data and database setup
- Controllers, routes, models, and configuration
- API for school-related resources

### Week 9
Advanced application development with integration and management features.
- School management API improvements
- Frontend dashboard integration
- More complete CRUD workflows
- Deployment-ready backend/frontend patterns

## Project Purpose
This repository serves as a learning archive for building REST APIs from scratch, understanding backend architecture, and connecting APIs with frontend applications using the practices taught in the CADT program.

## Notes
Each folder contains start code and exercise implementations for the corresponding weekly topic. The structure is organized by week and exercise, making it easy to follow the learning progression from basic backend concepts to full application development.
